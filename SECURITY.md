# Security policy

Please report suspected vulnerabilities privately through [GitHub's private vulnerability reporting form](https://github.com/ndycode/timetablekit/security/advisories/new). Do not open a public issue with credentials, private schedules, exploit details, or personal data.

Include the affected version or commit, a short impact description, and safe reproduction steps. Redact schedule content. The maintainer will acknowledge a report when possible, assess impact, and coordinate a fix or advisory.

TimetableKit does not promise that optional third-party AI providers retain no data. Review provider terms before enabling remote recovery.
