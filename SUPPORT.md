# Support

Use GitHub issues for reproducible bugs and feature requests. Use the [private vulnerability reporting form](https://github.com/ndycode/timetablekit/security/advisories/new) for security reports. Do not include private schedule data in public issues. Ask a private question through the same form when the report contains sensitive data.

When reporting a parser issue, include a synthetic or redacted input, expected normalized fields, the package version, and the command you ran. Never attach a real student schedule without permission.
