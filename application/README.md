# Vercel application package

This directory contains the prepared application answers, evidence map, reviewer script, and credit-use policy. It has not been submitted and is not evidence of selection or eligibility.

Before using the draft:

1. Re-open the [official Vercel Open Source Program page](https://vercel.com/open-source-program).
2. Check the exact application fields and current deadline.
3. Recheck every factual statement against the claims ledger.
4. Reconcile every factual sentence with [the claims ledger](../docs/claims.md).
5. Attach only public, licensed, synthetic, or explicitly shareable evidence.

The answer file is intentionally conservative. It does not assert MySched adoption, user impact, or application submission without direct evidence.
