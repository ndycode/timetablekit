# Vercel credit use

If selected, Vercel credits will be used only for the TimetableKit open-source project. The planned uses are public documentation and playground hosting, open-source preview deployments, serverless parse and export endpoints, optional AI recovery for the public demo, public examples, bandwidth, and privacy-safe observability.

Credits will not be used for MySched production traffic, private commercial workloads, unrelated sites or repositories, or marketplace-provider charges that are outside the program.

This is a policy and allocation plan. It is not evidence of awarded credits, actual spend, or selection.
