# Vercel Open Source Program evidence

The official program page was checked on September 1, 2026. It says the Summer cohort is open until September 13, 2026. It lists these requirements for consideration:

- An active open-source project.
- A project hosted on or intended to be hosted on Vercel.
- Measurable impact or growth potential.
- A Code of Conduct.
- Vercel credits used only for open-source projects.

The same page currently describes $3,600 in Vercel platform credits over 3 years. Recheck the page and the live application form immediately before submission.
