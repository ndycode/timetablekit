# Code of Conduct

TimetableKit is committed to a welcoming, harassment-free community for everyone, regardless of identity, background, experience, or status.

## Expected behavior

- Be respectful and specific.
- Assume good intent while addressing impact.
- Give feedback about the work, not the person.
- Protect private schedules, credentials, and personal information.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized conduct, impersonation, and deliberate exposure of private timetable data are not allowed.

## Reporting

Report a concern privately through the maintainer contact listed in [SUPPORT.md](SUPPORT.md). For suspected security vulnerabilities, use [GitHub's private vulnerability reporting form](https://github.com/ndycode/timetablekit/security/advisories/new). Do not include private schedules or credentials in a report. The maintainer will review reports, protect reporter privacy where practical, and document any public action without exposing personal details.

This code of conduct is adapted from the Contributor Covenant principles and is governed by the MIT-licensed project policy.
